What it does

Everything a term needs, in one window.

From first course search to a finished, shareable schedule — no browser tabs, no clashes, no guesswork.

Course search

Find any course, even when you can't spell it.

A fuzzy search over UW's live course catalogue means "cs 34" still finds CS 341. Type-ahead results, full course details, and "explore all" browsing per subject.

  • Typo-tolerant fuzzy matching (forked fuzzywuzzy-kotlin)
  • Live data from the UW OpenAPI
Weekly calendar

Drag your week together — clashes light up instantly.

Selected sections render as colour-coded blocks on a real weekly grid. Overlapping times are detected the moment they collide, so you never register into a conflict.

  • Automatic time-conflict detection
  • Calendar & list views, plus alternate calendars
Schedule optimizer

Let the solver find your perfect week.

A dedicated OptaPlanner service arranges your selected courses against real constraints — then hands back an optimized, conflict-free timetable in seconds.

  • Hard: zero overlapping courses
  • Medium: fewer days on campus  ·  Soft: minimal gaps
Personalization

Four calendar themes, your vibe.

Recolour the whole week with a tap — OCEAN, PASTEL, SUNSET, or EARTH. Small touch, but it makes the planner feel like yours.

  • Keyboard shortcuts for power users
Friends & sharing

Compare schedules, find your overlap.

Send friend requests, view each other's timetables, and spot the shared free time — planning group projects and lunch breaks without the back-and-forth.

  • Friend requests, incoming & sent
  • A wishlist to park courses for a future term
How it's built

A three-tier system, end to end.

A native desktop client talks to a Ktor API, which persists to PostgreSQL and offloads the hard scheduling maths to a separate OptaPlanner service. Course data streams in live from the University of Waterloo's OpenAPI.

Compose Desktop client→ Ktor REST API→ PostgreSQL ＋ OptaPlanner· UW OpenAPI
Client · presentation

Compose Desktop app

A Kotlin/JVM desktop UI built with Jetpack Compose — the weekly grid, conflict highlighting, themes, and a Ktor HTTP client for every request.

Kotlin · Compose · Material 3
Server · application

Ktor REST API

Routes for auth, courses, calendars, wishlist, and friends. Talks to Postgres through Exposed and calls the planner service for optimization.

Ktor · Exposed · Netty
Solver · data

OptaPlanner + Postgres

A standalone Spring Boot / OptaPlanner service solves the constraint model; PostgreSQL stores users, courses, calendars, and friendships.

OptaPlanner · Spring Boot · PostgreSQL
