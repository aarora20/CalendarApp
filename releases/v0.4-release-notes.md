# Release Notes for Sprint 4 (Last Sprint)
**Version:** 0.4  
**Release Date:** December 1, 2023

## Summary
Sprint 4, our last sprint, wraps up our current development phase with some exciting additions and enhancements. We've focused on bringing more flexibility and functionality to the app. This includes introducing dynamic themes for calendars, optimizing course scheduling with a new backend engine, and expanding the wishlist feature for multiple term planning. Plus, we've fine-tuned the user experience with small, yet significant, UX improvements and added a handy scroll bar to the wishlist page.

## What's New

### Dynamic Calendar Themes
- Introduced four new themes for the calendars, including main, alternate, and compare views.
- Added a convenient button to easily switch between different calendar themes.

### Course Scheduling Optimization
- Integrated a sophisticated optimization engine in our Spring Boot backend to streamline course scheduling.
- The new engine prevents overlapping timeslots and minimizes gaps, ensuring efficient timetabling.
- Implemented UI for adding courses to optimization list and functionality for sending the list to the backed engine to receive an optimized version.

### Enhanced Course Selection Interface
- Reworked the UI for easier course addition, especially for alternative schedules.
- Added a feature to optimize course schedules based on user selections with a single click.

### Multiple Term Wishlist Support
- Expanded the backend to support wishlists for multiple terms, linking it seamlessly with the frontend.
- Enhanced the wishlist UI to accommodate planning for multiple terms, allowing users to add courses for any upcoming term.

### Wishlist Page Usability Improvement
- Implemented a horizontal scroll bar in the wishlist page for better navigation through extensive course lists.

### Small UX Enhancements
- Implemented features to remember user preferences for screen size and calendar theme, enhancing personalized user experience.
- Added hot key and menu items for shortcuts. Such shortcuts include CTRL + S to go the course search page and CTRL + N to create a new alternate calendar.

## User Tips
- Explore the new calendar themes for a customized scheduling experience.
- Try out the optimized course scheduling for more efficient academic planning.
- Make the most of the multi-term wishlist for thorough course planning across different terms.

### Deployment to the Cloud
- Create Cloud SQL and Cloud Run instances on GCP to deploy our backend application to the cloud. Look forward to the eventual connection with our frontend.

## Looking Ahead
As we conclude this phase of development, we're excited to see how these new features will enhance your experience. We look forward to your feedback and are eager to continue improving our application based on your insights.
