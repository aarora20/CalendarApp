Release Notes for Sprint 1:
 
Version: 0.1
Release Date: Oct 20, 2023
Summary: In this sprint, we focused on backend integration with the UW OpenData API and implemented persistence for users and user courses. We also introduced several key features related to course management, and set the foundation for an improved user experience in the Course Planning Application for University of Waterloo students.
 
New Features:
1. Backend Integration with UW OpenData API: <br />
•	Custom routes have been implemented for fetching courses, schedules, terms and subjects by seamlessly integrating with the UW OpenData API. <br />
2. Search for Classes at the University: <br />
•	A search functionality has been added allowing students to browse and filter all available classes at the University of Waterloo for the current academic term. <br />
3. Course Information Page and Course Addition: <br />
•	When users select a course from the search bar, they're now presented with a detailed course information page showcasing the course title, description, and available schedules. <br />
•	Features buttons enabling users to conveniently add selected courses. <br />
4. Create Course Schedule List:<br />
•	Students can now add and remove classes to a user-friendly course schedule list. <br />
•	This list makes it easier to see and manage chosen classes for the term. <br />
5. Calendar View for Courses: <br />
•	Users can now visualize their selected courses in a calendar format. <br />
•	Course timings and days are displayed clearly, helping students grasp their schedule at a glance. <br />
6. Backend Persistence for User Course Selection Data and Users: <br />
•	H2 database was added to project and tables were defined to save users and user courses. <br />
•	API routes have been for saving and getting users and user courses, so users' course selections can now be stored in the database and will persist in the application. <br />
•	This ensures user data safety and allows for easy retrieval of saved schedules. <br />
 
Notes for Users: <br />
•	Please ensure your selected courses are saved regularly to avoid potential data discrepancies. <br />
•	If there are any mismatches or issues with course data, please cross-verify with official University of Waterloo resources. <br />
 
Upcoming in Sprint 2: <br />
Anticipate further enhancements to the user interface, increased integration features, and additional tools for course planning. Your feedback is always appreciated, and we're excited to bring even more functionality to this application in the upcoming sprint. Stay tuned!
