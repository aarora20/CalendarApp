(c) Release Notes for Sprint 1:
 
Version: 1.0.0
Release Date: Oct 20, 2023
Summary: In this sprint, we focused on backend integration with the UW OpenData API, introduced several key features related to course management, and set the foundation for an improved user experience in the Course Planning Application for University of Waterloo students.
 
New Features:
1.	Backend Integration with UW OpenData API:
a)	Custom routes have been implemented for fetching courses, schedules, terms and subjects by seamlessly integrating with the UW OpenData API.
2.	Course Information Page and Course Addition:
a)	When users select a course from the search bar, they're now presented with a detailed course information page showcasing the course title, description, and available schedules.
b)	Features buttons enabling users to conveniently add selected courses.
3.	Calendar View for Courses:
a)	Users can now visualize their selected courses in a calendar format.
b)	Course timings and days are displayed clearly, helping students grasp their schedule at a glance.
4.	Search for Classes at the University:
a)	A search functionality has been added allowing students to browse and filter all available classes at the University of Waterloo for the current academic term.
5.	Persisting User Course Selection Data:
a)	Users' course selections and wishlists are now stored persistently in a database.
b)	This ensures user data safety and allows for easy retrieval of saved schedules and wishlists.
6.	Create Course Schedule List:
a)	Students can now add and remove classes to a user-friendly course schedule list.
b)	This list makes it easier to see and manage chosen classes for the term.
 
Notes for Users:
•	Please ensure your selected courses are saved regularly to avoid potential data discrepancies.
•	If there are any mismatches or issues with course data, please cross-verify with official University of Waterloo resources.
 
Upcoming in Sprint 2:
Anticipate further enhancements to the user interface, increased integration features, and additional tools for course planning. Your feedback is always appreciated, and we're excited to bring even more functionality to this application in the upcoming sprint. Stay tuned!
