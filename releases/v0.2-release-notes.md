Release Notes for Sprint 1:

Version: 0.2
Release Date: Nov 3, 2023
Summary: In this sprint, we focused on implementing the wishlist feature, the friends and compare system feature, and
the authentication feature. We also worked on important orchestration tasks such as setting up Docker Compose for our 
server and database tasks such as migration to a Postgres database. We also improved user experience in terms of the UI, 
accessibility, and responsiveness in our application.


New Features:
1. Backend Implementation for Authentication: <br />
   •	Custom API routes have been implemented for logging in users and registering users as well as saving users to database with password hashing. <br />
2. Backend Implementation for Friends: <br />
   •	Custom API routes have been implemented for friendships. Users can send friend requests, accept or deny incoming requests, view friends, and delete friendships. Friendships are also persisted in the database. <br />
   •	Postgres extension has also been added to implement string matching capabilities for queries to search for users. <br />
3. Backend Implementation for Wishlist Courses: <br />
   •	Custom API routes have been implemented for saving, getting, and deleting wishlist data for users and the data can now be stores in the database. <br />
4. Wishlist View in App:<br />
   •	Students can now add and remove classes to a wishlist. <br />
5. Improved View for Calendar: <br />
   •	Calendar view now supports lines to delineate the times and is responsive to screen size changes. <br />
6. Friend View in App: <br />
   •	New section in app for friends system. Sidebar has been implemented for switching between the options <br />
   •	Users can search for users, sent them friend requests, view pending request from other users and accept/reject them, view current friends, and compare calendars <br />
   •	Users can compare calendars with friends that they added. In the compare calendar view, they can toggle to see both calendar, or just their own/just their friend's. <br />
7. Other Development Features
   •    Dockerfile has been added to build app in Docker container from jar file. Docker compose file has been added to set up the containers to run the server and the database. <br />
   •    App's database has been migrated to a Postgres database.

Notes for Users: <br />
•	Please ensure your selected courses are saved regularly to avoid potential data discrepancies. <br />
•	If there are any mismatches or issues with course data, please cross-verify with official University of Waterloo resources. <br />

Upcoming in Sprint 3: <br />
Anticipate further enhancements to the user interface, increased integration features, and additional tools for course planning. More robust authentication implementation is also being planned. Your feedback is always appreciated, and we're excited to bring even more functionality to this application in the upcoming sprint. Stay tuned!
